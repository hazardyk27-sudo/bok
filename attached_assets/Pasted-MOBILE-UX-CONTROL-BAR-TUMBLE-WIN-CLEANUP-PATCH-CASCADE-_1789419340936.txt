MOBILE UX / CONTROL BAR / TUMBLE WIN CLEANUP PATCH — CASCADE 8

Modify the EXISTING Cascade 8 project.

Do NOT change:
- RNG
- payout math
- symbol probabilities
- tumble logic
- bonus logic

This patch is ONLY about UI / mobile UX / control layout / presentation polish.

==================================================
1. MOBILE SOUND LABEL SHORTENING
==================================================

On mobile, horizontal space is very valuable.

The current full label like:
"Sound on"

is too long and takes unnecessary width.

Required change:
- shorten the sound control label on mobile
- preferred options:
  - icon only
  - "Sound"
  - "SFX"

Choose the cleanest / most premium option.

Important:
- desktop can keep a fuller label if it still looks clean
- mobile should use the more compact version
- keep the control clear and easy to understand

==================================================
2. START AUTO / AUTO UX REDESIGN
==================================================

The current auto-spin UX should be redesigned.

Do NOT keep a permanently visible awkward combination like:
- dropdown
- start auto button

For mobile especially, this should become much cleaner.

Required new behavior:
- show a single compact button:
  AUTO
- when tapped, open a small premium popover / menu
- options:
  10
  25
  50
  100
- after the user selects one, auto-spin becomes active / selectable in a clean way

The experience should feel premium and intentional.

Goal:
AUTO should behave like one elegant compact control,
not like a clunky form UI.

==================================================
3. AUTO CONTROL POSITIONING
==================================================

On mobile, AUTO should sit as a compact module just to the LEFT of the main Spin button.

This is part of the intended mobile control hierarchy.

Required mobile hierarchy:

LEFT:
Bet control

LEFT-CENTER / just left of Spin:
AUTO control

CENTER:
Large Spin button

RIGHT:
Turbo
Sound

This hierarchy should be implemented clearly.

==================================================
4. MOBILE CONTROL HIERARCHY
==================================================

Implement this mobile-first layout:

- Bet control on the left
- AUTO small premium module just left of Spin
- Spin button centered and dominant
- Turbo and Sound on the right

This structure must be:
- visually balanced
- easy to tap with one thumb
- compact
- premium
- clearer than the current layout

Do NOT leave the controls feeling scattered.

==================================================
5. BET CONTROL
==================================================

Keep Bet as a compact premium control on the left.

Preferred structure:
[-] amount [+]

Example:
[-] 500.00 [+]

Requirements:
- easy tap targets
- clean alignment
- compact width
- premium visual treatment

==================================================
6. SPIN BUTTON
==================================================

Spin remains the hero action.

Requirements:
- centered
- large enough for mobile tapping
- premium styling
- strong visual hierarchy
- not childish
- not too bulky

It must remain the main focus of the control dock.

==================================================
7. TURBO + SOUND GROUP
==================================================

Turbo and Sound should form the right-side utility group.

Requirements:
- compact
- premium
- same height / same family
- clear icons
- mobile-friendly tap targets

The Sound control on mobile should use the shortened presentation from section 1.

==================================================
8. TUMBLE WIN TITLE CLEANUP
==================================================

Clean up the Tumble Win presentation.

Two acceptable directions:
A) very small subtle "TUMBLE WIN" label above the amount
B) remove the title completely and show only the amount

Implement the cleaner, more premium option.

The goal is a less cluttered result area.

If the panel still looks elegant without the title,
prefer removing it entirely.

If a title is kept:
- make it much smaller
- elegant
- subtle
- secondary to the amount

==================================================
9. TUMBLE WIN PRESENTATION PRIORITY
==================================================

The tumble result area should focus on the money amount.

It should not be text-heavy.

The player’s eye should immediately go to:
the result amount

Everything else should be secondary or removed.

This area should feel:
- premium
- minimal
- modern
- elegant
