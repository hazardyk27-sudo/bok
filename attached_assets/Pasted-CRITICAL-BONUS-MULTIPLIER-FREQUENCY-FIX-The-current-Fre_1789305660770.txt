CRITICAL BONUS MULTIPLIER FREQUENCY FIX

The current Free Spin multiplier behavior is far too sparse.

A real 10-Free-Spin bonus just completed with ZERO Multiplier Cores.

The main architectural reason is that Multiplier Cores are currently restricted to:

BONUS_REFILL

This means a Core can only appear AFTER a normal-symbol win creates empty cells.

If a Free Spin does not win, it has zero multiplier opportunities.

If several Free Spins have no tumble, an entire 10-spin feature can easily contain no multipliers.

This does NOT create the intended bonus experience.

FIX THE SPAWN ARCHITECTURE.

Do NOT change the already-correct sequence-level multiplier settlement logic.

==================================================
1. MULTIPLIERS ARE NOW ALLOWED ON BONUS INITIAL BOARD
==================================================

Change generation contexts to:

BASE_INITIAL:
normal symbols
Scatter
NO Multiplier Core

BASE_REFILL:
normal symbols
very rare Base Multiplier Core
NO Scatter

BONUS_INITIAL:
normal symbols
Scatter
Multiplier Cores

BONUS_REFILL:
normal symbols
Multiplier Cores
NO Scatter

This is the critical change.

A Free Spin must be able to start with:

normal symbols
+
one or more Multiplier Cores

even before the first tumble.

2. MULTIPLIERS STILL DO NOT PAY BY THEMSELVES
==================================================

A Core on the initial Free Spin board does NOT create a win.

Example:

initial board contains:

25x Core

but there is no 8+ normal-symbol win.

Result:

0 payout.

The 25x disappears when that Free Spin/tumble sequence ends.

Do not pay:

0 × 25.
