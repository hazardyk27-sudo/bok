CRITICAL TUMBLE MULTIPLIER TIMING FIX

The current multiplier presentation/timing is incorrect.

Right now, the X multiplier effect / animation appears again after each explosion inside the same tumble chain.

This is WRONG.

We must change the sequence so that multiplier symbols are accumulated silently during the tumble chain, and the multiplier animation / effect is triggered ONLY AFTER the entire tumble sequence is finished.

==================================================
CORRECT BEHAVIOR
==================================================

Within one paid spin:

1. Evaluate the grid
2. If there is a win:
   - mark winning symbols
   - explode winning symbols
   - let symbols fall / refill
   - continue checking for new wins
3. If multiplier symbols appear during any tumble step:
   - collect/store them internally
   - DO NOT trigger their main animation yet
   - DO NOT apply multiplier yet
   - DO NOT replay large multiplier burst effects after each individual explosion

Repeat this until:

- no more wins exist on the board
- the tumble chain is fully complete

ONLY AFTER THAT:

4. Trigger the multiplier resolution phase once
5. Show the multiplier symbols clearly
6. Play the main X multiplier animation once
7. Sum all collected multipliers for that spin/tumble chain
8. Apply the total multiplier to the accumulated tumble payout
9. Show final payout update

==================================================
IMPORTANT VISUAL RULE
==================================================

During intermediate tumbles:

- multiplier symbols may appear on the board
- they may have a subtle idle effect / glow
- but NO full activation animation
- NO big burst animation
- NO payout application yet

The full multiplier animation must happen only once,
after all cascades/explosions of that spin are finished.

==================================================
EXAMPLE
==================================================

Suppose one spin goes like this:

- first win explodes
- second win explodes
- third win explodes
- multipliers 2x and 5x appeared during the chain

Current wrong behavior:
- 2x animates after first/second explosion
- 5x animates again later
- repeated effect spam happens

Correct behavior:
- both multipliers are collected silently
- tumble chain continues normally
- after the final tumble ends and no more wins remain:
    -> show multiplier activation phase once
    -> animate 2x and 5x together
    -> total multiplier = 7x
    -> apply 7x once to the total tumble win

Refactor the spin/tumble pipeline into separate phases:

==================================================
STATE REQUIREMENTS
==================================================

Maintain something like:

currentSpinMultiplierSymbols = []
currentSpinBaseTumbleWin = 0

During each tumble:
- append any newly landed multiplier symbols to currentSpinMultiplierSymbols
- add tumble win to currentSpinBaseTumbleWin

After no more wins:
- compute totalMultiplier from currentSpinMultiplierSymbols
- trigger one multiplier animation phase
- finalWin = currentSpinBaseTumbleWin * totalMultiplier
- then clear multiplier state for next spin
