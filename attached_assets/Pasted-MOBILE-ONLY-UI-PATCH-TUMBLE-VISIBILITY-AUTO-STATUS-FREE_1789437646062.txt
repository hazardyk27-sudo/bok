1. REMOVE THE EXTRA MOBILE STATUS CARD UNDER THE GRID
==================================================

Right now on mobile there is an extra status card below the grid showing things like:
- AUTO SPINS LEFT
- a large number

This is causing the tumble / win area to get pushed down or visually crowded.

Required change:
- remove that separate large mobile status card completely
- do NOT show a second duplicate status block under the grid
- the tumble / win area must remain clearly visible and must not be pushed out of view by redundant status UI

Main goal:
- on mobile, the tumble / win display must stay fully visible, clean, readable, and properly fitted both in normal play and in free spins

2. AUTO STATUS MUST LIVE INSIDE THE AUTO CONTROL ROW
==================================================

On mobile, the remaining auto spins already appear in the STOP AUTO row.
That is the correct place.

Required change:
- use the AUTO row itself as the main status display
- do NOT duplicate the information elsewhere
- remove empty or wasted space inside the AUTO row
- use that space to display the remaining count clearly

Required mobile AUTO row structure while auto is active:
[ STOP AUTO ] [ 25 LEFT ]

Requirements:
- the right-side remaining count area must be larger and more readable
- the number must be big, clean, modern, and centered
- it should fill the right-side space properly
- do not leave an awkward empty gap next to STOP AUTO
- typography should be more premium and legible
- the right side should visually feel like a proper info panel, not a tiny badge

When auto is NOT active:
[ START AUTO ] [ selected amount ]

Example:
[ START AUTO ] [ 25 ]
