# 3. CORE CASCADE RULE

After the board settles:

1. Count every normal symbol S1-S8.
2. Find all symbols having count >= 8.
3. Calculate all winning symbol payouts.
4. Add all winning symbol payouts together.
5. Highlight every winning instance.
6. Animate those symbols.
7. Remove ALL instances of every winning symbol from the board.
8. Apply gravity independently to each column.
9. Existing symbols fall into lower empty positions.
10. Generate replacement symbols above the grid.
11. Animate replacements falling down.
12. Evaluate the new board.
13. Repeat until no symbol has 8+ instances.

This is one paid spin.

There is NO artificial limit on tumble count.

The only hard limit is MAX WIN.

Then remove ALL 9 S1 symbols and ALL 8 S6 symbols simultaneously.

Do NOT execute one symbol first and the other afterward.
