---
name: Third-position repeat semantics
description: The intended relationship between pair-internal copies and the next group’s natural weighted repeat.
---

The third cell above a visible pair must not have a separate direct-copy branch. It should be selected from the normal weighted reel, with only the visible pair symbol’s natural weight multiplied by 0.5; the pair’s second cell keeps its independent 75% copy behavior.

**Why:** A 50% third-cell copy branch makes the total third-symbol repeat rate look like roughly 50%, which is not the requested 14% → 7% natural-weight attenuation.

**How to apply:** Keep pair-copy metrics separate from third-position fallback metrics. For a 14%-weight symbol, expect about 7% conditional repeat in the third weighted selection.
