# Cascade 8

Cascade 8 is a polished browser prototype for a 6 × 5 cascading, anywhere-pays game using virtual demo credits only. It is intentionally not a real-money gambling product: there are no deposits, withdrawals, payment processors, cash-out flows, or real-money wallets.

## Run

```bash
pnpm install
pnpm run dev
```

Open the Replit preview. The development harness is available at `/lab`.

## Build and test

```bash
pnpm run typecheck
pnpm test
pnpm run build
```

## Simulation

The simulator uses the exact same symbol weights, RNG interface, paytable, win evaluator, cascade logic, bonus rules, and crystal logic as the game. It never imports Phaser.

```bash
pnpm run simulate -- --spins=100000 --seed=12345
pnpm run simulate -- --spins=1000000 --seed=20260913
```

Reports are printed to the console and written to `simulation-results/` with the seed and timestamp.

## Architecture

- `src/engine/` contains pure game math and deterministic tests.
- `src/config/GameConfig.ts` is the single editable source for board dimensions, weights, paytable, bonus tables, crystal distribution, bets, and the max-win cap.
- `src/game/` contains Phaser rendering, animation orchestration, audio, and the explicit controller state machine.
- `src/simulation/` contains the non-Phaser simulator and CLI.
- `src/main.ts` builds the surrounding HTML/CSS interface and connects it to the Phaser scene.

Phaser is never the source of truth. A board is pure symbol data; the scene renders it and animates the events produced by the engine.

## Math rules

- Initial boards deal 30 cells using the configured S1–S8 and SCATTER weights.
- 8 or more copies of the same normal symbol anywhere on the board win.
- Every winning symbol group is evaluated simultaneously, removed simultaneously, and then refilled with normal symbols only.
- Scatter is only generated on the initial board of a paid spin or free spin. It is never generated by cascade refills.
- The base scatter table is 4 → 10 Free Spins, 5 → 12, 6+ → 15.
- Free-spin retriggers are 3 → +5, 4 → +8, 5 → +12, 6+ → +15.
- Crystals are free-spin-only overlays that resolve after a winning tumble. Their values add together and multiply that tumble subtotal only.
- The originating paid spin is capped at 5000x bet across its base cascades and complete bonus.
- The player is charged once at spin start and credited once when the originating spin finishes.

## Final V1 math configuration

Initial symbol weights remain:

| S1 | S2 | S3 | S4 | S5 | S6 | S7 | S8 | SCATTER |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 17% | 15.5% | 14% | 12.5% | 11.5% | 10% | 9% | 8% | 2.5% |

The provided paytable is used without player-dependent changes. To keep bonus RTP within the target range while retaining the requested free-spin and scatter rules, the static crystal-count calibration is:

- 0 crystals: 95%
- 1 crystal: 4%
- 2 crystals: 1%
- 3 crystals: 0%

Crystal multiplier weights remain 2x 40%, 3x 25%, 5x 15%, 10x 10%, 25x 6%, 50x 3%, 100x 1%.

No player history, balance, bet size, win/loss history, inactivity, or autoplay behavior changes any outcome probability.

## Replacing art and timing

The prototype uses original vector-like Phaser shapes and typography instead of external game artwork. Symbol colors, names, and icons are in `src/config/GameConfig.ts`; the renderer is `src/game/GameScene.ts`.

Animation durations are in `ANIMATION` in `src/config/GameConfig.ts`. Turbo and reduced-motion change timing only, never the RNG or mathematical result.

## RNG safety note

The playable prototype uses browser `crypto.getRandomValues()` and is suitable for this virtual-credit demo. A regulated real-money product would need an appropriately certified server-side RNG/gaming platform and independent certification. Browser RNG in this prototype is not a substitute for that process.
