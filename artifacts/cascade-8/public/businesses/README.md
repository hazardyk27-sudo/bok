# Businesses card images

Drop the final business artwork into this folder using these exact filenames:

- `stadium.png`
- `club-store.png`
- `fan-club.png`

Recommended source size: **1600 × 900** (16:9), PNG or WebP-quality artwork exported as PNG for the current fixed paths.

The Businesses UI keeps the image region at 16:9 and uses `object-fit: cover`. If an image file is missing, the card stays on the built-in dark placeholder instead of showing a broken-image icon.
